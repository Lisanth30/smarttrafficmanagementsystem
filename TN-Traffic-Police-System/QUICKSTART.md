Use the sliders to change:
- Green light duration (how long green stays on)
- Yellow light duration (warning time)
- Vehicle spawn rate (how many vehicles appear)

## 🚗 Understanding the Simulation

### Roads Layout:
```
              NORTH
                ↓↑
                ||
    WEST ←← === ⊕ === →→ EAST
                ||
                ↓↑
              SOUTH
```

### Vehicle Types:
- **Rectangles** 🟦 = Cars (larger, slower)
- **Lines** ━ = Bikes (smaller, faster)

### Signal Colors:
- **🟢 Green** = GO! Vehicles move through
- **🟡 Yellow** = SLOW DOWN! Prepare to stop
- **🔴 Red** = STOP! Vehicles wait

### How It Works:
1. Signals alternate between East-West and North-South
2. When a signal is GREEN, vehicles from that direction can pass
3. When a signal turns RED, vehicles stop at the stop line
4. After the timer, signals switch to the other direction
5. Vehicles that pass through are counted in statistics

## ⚙️ Adjusting Settings

### Green Light Duration (3-15 seconds)
- **Lower**: Faster signal changes, more stopping
- **Higher**: Longer green time, better flow

### Yellow Light Duration (1-5 seconds)
- **Lower**: Quick transition
- **Higher**: More warning time

### Vehicle Spawn Rate (1-10)
- **Lower**: Less traffic, quieter roads
- **Higher**: More traffic, busier roads

## ❓ FAQ

**Q: The simulation isn't starting?**
A: Make sure you clicked "Start Simulation" button. It should turn green and say "🟢 Running"

**Q: Too many vehicles on screen?**
A: Lower the "Vehicle Spawn Rate" slider and click Reset

**Q: Can I change signal timing?**
A: Yes! Use the sliders at the top before or during simulation

**Q: How do I go back to dashboard?**
A: Click the "← Back" button at the top left

**Q: Can I run multiple simulations?**
A: Open multiple browser tabs with the same login!

**Q: Does it save my data?**
A: Registered users are saved in browser's local storage

## 🆘 Troubleshooting

### Problem: Page is blank
**Solution**: Make sure you're opening `login.html` not other files

### Problem: Can't login
**Solution**: Double-check username and password (case-sensitive!)

### Problem: Vehicles not moving
**Solution**: Click "Start Simulation" - status should show "🟢 Running"

### Problem: Everything is too slow
**Solution**: Close other browser tabs and applications

### Problem: Can't see the map properly
**Solution**: Zoom out using Ctrl + Mouse Wheel or Ctrl + Minus key
